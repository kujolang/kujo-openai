# Support

Use [Kujo OpenAI issues](https://github.com/kujolang/kujo-openai/issues) for reproducible non-sensitive problems. Include plugin version, OS/architecture, Kujo version and diagnostic status. Do not post tokens, private repository contents, receipts, full local paths or raw environment dumps.

For installation, use the [official Kujo guide](https://github.com/kujolang/kujo/blob/main/docs/ECOSYSTEM_INSTALL.md). Restart/reconnect only after resolving a startup error; do not repeatedly retry a potentially effectful operation.

Report sensitive security issues privately through GitHub's vulnerability-reporting interface if enabled. If unavailable, request a private contact channel without disclosing exploit details publicly. No unverified support email is provided.

The native-only plugin and public local-MCP route remain blocked. Opening a developer ZIP or successfully running preflight is not directory installation or acceptance.
